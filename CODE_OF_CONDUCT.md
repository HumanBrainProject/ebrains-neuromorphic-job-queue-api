# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant], which
governs participation in our community spaces — issues, merge requests, code
review, and any other project-related communication.

The full text is available at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- A plain-text copy: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>

## Reporting

If you believe someone is violating the Code of Conduct, please report it
confidentially to the project maintainer:

- Andrew Davison — <andrew.davison@cnrs.fr>

All reports will be reviewed and investigated promptly and fairly. The
maintainer is obliged to respect the privacy and security of the reporter
of any incident.

## Enforcement

Maintainers will follow the [Community Impact Guidelines][guidelines] from
the Contributor Covenant when determining the consequences of any action
they deem in violation of this Code of Conduct.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[guidelines]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
